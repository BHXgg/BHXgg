### 🔧 Featured: GTWM, a mod loader for *Get To Work*

A lightweight mod loader for a Unity 6 game, built from scratch. Mods inject with **zero game files modified**, **hot-reload** while the game runs, and share one UI kit, config system and Harmony patching layer.

| Project | What it does |
|---|---|
| [**GTWM**](https://github.com/BHXgg/GTWM) | The loader: Doorstop injection, hot reload, per-mod isolation, shared frosted-glass UI kit |
| [**Multiplayer**](https://github.com/BHXgg/GTWM-Multiplayer) | Co-op for a single-player game: own TCP netcode, LAN discovery, spectating, chat, host rules |
| [**Model Changer**](https://github.com/BHXgg/GTWM-ModelChanger) | Wear any `.glb` model, skinned to the game's own skeleton and synced in multiplayer |
| [**Model Converter**](https://github.com/BHXgg/GTWM-ModelConverter) | Desktop tool: any 3D model in, rigged and fitted game character out |
| [**Mod Manager**](https://github.com/BHXgg/GTWM-ModManager) | Enable, disable and hot-reload mods in game, with a live log viewer |
| [**Cheat Menu**](https://github.com/BHXgg/GTWM-CheatMenu) | Noclip, teleports, position slots, physics tweaks, with leaderboard protection |
| [**FPS Limiter**](https://github.com/BHXgg/GTWM-FpsLimiter) | Rebindable frame-rate caps and an FPS counter |
