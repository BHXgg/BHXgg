01 · Flagship

GTWM: a mod loader, built from scratch

Get To Work Mod Loader

A lightweight loader for a Unity 6 (Mono) game. Mods inject without touching a single game file, hot-reload while the game runs, and share one UI kit, config system and Harmony patching layer.

Unity 6 Mono.NET Framework 4.7.2HarmonyDoorstop injectionMIT
COREGTWM LoaderZero-touch injection, hot reload from bytes, per-mod isolation, crash auto-disable, version safety. F10MultiplayerCo-op for a single-player game: own TCP netcode, LAN discovery, spectate, chat, host rules. F9Model ChangerWear any .glb model, skinned to the game skeleton and synced to everyone (SHA-256 verified). EXEModel ConverterAny 3D model in, rigged and fitted character out. Retargets humanoids, auto-rigs the rest. F8Mod ManagerEnable, disable and hot-reload mods in game; auto-reload on rebuild; live log viewer. Frostfold
An iPhone Duo-style frosted-glass fold transition for Android foldables, book-style and flip. It reads the hinge sensor in real time and compares it with the gyroscope to work out which half of the phone is moving, then blurs only that half.
